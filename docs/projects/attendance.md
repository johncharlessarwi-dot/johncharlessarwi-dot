# AFAMS / John Attendance System

**Focus:** Academic attendance  
**Repository:** [JOHN-ATTENDANCE-SYSTEM](https://github.com/johncharlessarwi-dot/JOHN-ATTENDANCE-SYSTEM)  
**Visibility:** public

## Problem being explored

Institutions need reliable check-ins that resist impersonation and give lecturers a useful review workflow.

## Engineering scope

Role-specific academic workflows, time-limited codes, QR support, optional location checks, and class administration.

## What a reviewer should examine

Evaluate server-side verification, permissions, location-data minimization and exceptions for connectivity or device failures.

## Status and access notes

Operational readiness depends on configuration, controls and institutional approval.

For implementation details, see the linked repository documentation when you have access. This summary avoids claiming production readiness beyond published evidence.
