# SafariOS / Tourism Agent

**Focus:** Tourism planning prototype  
**Repository:** [agentic-tourism-platform](https://github.com/johncharlessarwi-dot/agentic-tourism-platform)  
**Visibility:** public

## Problem being explored

Tour operators need destination discovery and itinerary preparation without implying bookings are confirmed.

## Engineering scope

Early-stage destination explorer, itinerary planning concepts, information pages and enquiry qualification.

## What a reviewer should examine

Evaluate destination source accuracy, explicit consent to send enquiries and separation of demo data from confirmed availability.

## Status and access notes

The repository states that its enquiry API does not book tours, take payments or save leads.

For implementation details, see the linked repository documentation when you have access. This summary avoids claiming production readiness beyond published evidence.
