# JobCraft AI

**Focus:** Career-document builder  
**Repository:** [JOB-CRAFT-AGENTIC-AI](https://github.com/johncharlessarwi-dot/JOB-CRAFT-AGENTIC-AI)  
**Visibility:** private

## Problem being explored

Job seekers need adaptable CV workflows without fabricated content or confusing export options.

## Engineering scope

Four career pathways, editable drafts, templates, bilingual labels, browser PDF printing, optional device autosave and validated backups.

## What a reviewer should examine

Evaluate user control over locally stored personal data, template accessibility, and clear disclosure of preview-only features.

## Status and access notes

The repository describes a local browser preview, not a released SaaS product; source code is private.

For implementation details, see the linked repository documentation when you have access. This summary avoids claiming production readiness beyond published evidence.
