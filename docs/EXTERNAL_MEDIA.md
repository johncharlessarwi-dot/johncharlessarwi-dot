# External media and availability

The public profile uses third-party services for some badges, animated headings, language summaries, coding activity graphs, and profile trophies. These are illustrative widgets, not authoritative evidence of project quality or current repository activity.

## Rendering limitations

- External widgets may be rate-limited, unavailable, or cached.
- Service outages can cause an image to disappear while the underlying profile is still available.
- Reduced-motion preferences may not be respected by every remote animated service.
- Live counts displayed by a badge may lag behind GitHub itself.

## Privacy and maintainability

Opening the README may cause the browser to request images from external services. Prefer local SVG assets for essential content. Do not embed private information, secret tokens, or authenticated endpoints in image URLs. Keep essential project links and contact details as accessible text, not solely within third-party images.
