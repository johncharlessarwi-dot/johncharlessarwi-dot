# Contributing to the developer profile

This repository powers the public GitHub profile for **John Charles Sarwi**. Contributions should improve accuracy, accessibility, links, design, and maintainability.

## Before making a change

1. Confirm that a project link is correct and that the destination is publicly accessible before describing it as a public project.
2. Never add passwords, API keys, user details, private source code, or unpublished customer information.
3. Keep claims factual: a concept, prototype, or private project must not be presented as a deployed production service.
4. Prefer locally stored, accessible SVG illustrations over large decorative images or tracking-heavy widgets.

## Verify your changes

Use Node.js 22 or newer:

```sh
npm run check
```

Review the rendered Markdown and ensure animated assets have static fallback content and respect reduced-motion preferences.

## Commit policy

Use one narrowly scoped, useful change per commit. Do not fabricate or duplicate commits to increase contribution counts. Prefer a pull request for outside contributions; maintainers can commit directly after validation.

## Reporting a correction

Open a documentation issue describing the exact outdated claim or link, the expected correction, and a verifiable source. Do not publish security issues in a public issue; use the security contact instructions.
